# Project: Emoji linter python script

Emojis are stupid and don't belong in programming, documentation, or in audio. 

## Task

Let's design a python script that can be run as part of the ci/cd process to proactively hunt, and alert upon any emojis that may have leaked into the codebase.

- No emojis
- Typography using ascii is fine.

- Should regex against new commits and exit without error if it finds none, and throw an error if it does. 
- This should alert the application build process and the build can be cancelled.
